A 2D analogue of Instant-NGP's multi-resolution feature grid. Drag the query point in any panel — it moves in all three at once. In interpolate mode each level draws the four corner vertices used for bilinear interpolation. In gather neighborhood mode each level instead returns the K nearest vertices as a sequence — the same data, restructured for a downstream attention layer to reason about. Vertex colors are a deterministic hash, a stand-in for the embeddings the network actually learns to store.
