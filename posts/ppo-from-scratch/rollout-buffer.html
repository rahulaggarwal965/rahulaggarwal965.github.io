A 24-step rollout buffer filling left-to-right. Episode boundaries close out an advantage-computation window: termination uses a bootstrap value of 0, truncation bootstraps from V(slast). When the buffer fills mid-episode (the unterminated tail at the right), we still bootstrap from V(slast) before training. This is the only thing that lets one buffer hold many episodes worth of partial trajectories.
